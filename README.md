# QR Studio

מחולל קודי QR מעוצבים, בעברית מלאה. מדביקים קישור, בוחרים עיצוב וגודל, ומורידים תמונה או PDF.
הכול רץ בדפדפן — הקישור, הלוגו והתמונות לא נשלחים לשום שרת.

## מה יש בפנים

- **15 עיצובים מוכנים** — מקלאסי שחור-לבן ועד גרדיאנטים זורמים, ניאון וזהב על שחור.
- **התאמה מלאה** — 10 צורות מודול, 6 מסגרות עיניים, 6 מרכזי עיניים, צבעים וגרדיאנטים,
  גודל מודולים, עיגול פינות, שוליים ורמת תיקון שגיאות.
- **לוגו במרכז** — עם פינוי מודולים אוטומטי מתחתיו והעלאת רמת תיקון השגיאות.
- **כיתוב מתחת לקוד** — בחמישה סגנונות מסגרת שמותאמים אוטומטית לעיצוב שנבחר.
- **17 גדלים נפוצים** — דיגיטל (256–4096px), הדפסה ב‑300DPI (2–15 ס״מ), ורשתות
  (פוסט אינסטגרם, סטורי, כרטיס ביקור, פלייר A5, כרזת A4).
- **ייצוא** — PNG, JPG, SVG ו‑PDF; שיתוף ישיר דרך תפריט המכשיר; העתקה ללוח.
- **הורדת רקע** — ייצוא הקוד בלבד, עם שקיפות, להנחה על עיצוב קיים.
- **בדיקת סריקה אמיתית** — כל קוד מפוענח בחזרה לפני שהוא מוצג כתקין (ראו למטה).
- **PWA** — התקנה למסך הבית ועבודה מלאה במצב לא‑מקוון.
- **מצב כהה** מלא, RTL אמיתי, ותמיכה ב‑`prefers-reduced-motion`.

## פריסה ל-Firebase Hosting

הפרויקט כבר מקושר ל‑`qr-generator-92987` דרך `.firebaserc`.

```bash
npm install -g firebase-tools
firebase login        # פעם אחת, בדפדפן
npm run deploy
```

בסביבת CI (בלי דפדפן) צריך אסימון שירות:

```bash
firebase login:ci                       # מפיק אסימון
FIREBASE_TOKEN=<האסימון> firebase deploy --only hosting
```

לאחר הפריסה כדאי לוודא ב‑Firebase Console שהדומיין מופיע תחת
**Authentication → Settings → Authorized domains**, כדי ש‑Analytics יעבוד.

## ארכיטקטורה

הרעיון המרכזי: **מקור גאומטרי אחד, שני רנדררים.**

```
טקסט ──► encode.ts ──► מטריצת מודולים
                            │
                            ▼
                      geometry.ts  ──► QrGeometry (נתיבי SVG ביחידות "מודול")
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
     render/svg.ts                 render/canvas.ts
   (תצוגה חיה + ייצוא SVG)      (ייצוא PNG / JPG / PDF)
```

`QrGeometry` מתאר את הקוד כנתיבי וקטור ביחידות מודול — בלי פיקסלים ובלי DOM.
שני הרנדררים מקבלים בדיוק את אותם נתיבים ואת אותם אזורי גרדיאנט, ולכן **מה
שרואים על המסך זהה למה שיורד כקובץ**, ואותה גאומטריה נשארת חדה ב‑256 פיקסל
ובכרזת A4 כאחד.

| קובץ | תפקיד |
|------|-------|
| `src/lib/qr/encode.ts` | קידוד טקסט למטריצת מודולים |
| `src/lib/qr/paths.ts` | בוני נתיבי SVG (`d`) — ריבוע, עיגול, מעוין, ניצוץ, פילֶה קעור… |
| `src/lib/qr/geometry.ts` | מטריצה + עיצוב ← גאומטריה מלאה |
| `src/lib/qr/presets.ts` | 15 העיצובים |
| `src/lib/qr/render/*` | רנדרר SVG ורנדרר Canvas |
| `src/lib/pdf.ts` | כותב PDF מינימלי (ראו למטה) |
| `src/lib/contrast.ts` | בדיקת ניגודיות WCAG לצורכי סריקה |
| `src/lib/verify.ts` | פענוח חוזר של הקוד שנוצר |

### למה PDF בכתיבה עצמית

ספריות ה‑PDF הנפוצות גוררות `html2canvas` ו‑`DOMPurify` — יותר מ‑600KB — בשביל
יכולות שלא בשימוש כאן. `src/lib/pdf.ts` כותב עמוד יחיד עם תמונה אחת בכ‑170 שורות,
עם דחיסת FlateDecode ללא אובדן (חשוב: ארטיפקטים של JPEG סביב קצוות חדים פוגעים
בסריקה). התוצאה: 2.3KB במקום 400KB.

## איך נשמרת הסריקוּת

עיצוב יפה שלא נסרק הוא באג. שלוש שכבות הגנה:

1. **גאומטריה** — צורות "רזות" (ניצוץ, צלב, מעוין) מנופחות במקדם קבוע כדי שהמודול
   יישאר כהה מספיק; קיטום העיניים מוגבל כדי לא לשבור את יחס 1:1:3:1:1 שסורקים
   מחפשים; גלגל העין לעולם לא גולש אל טבעת ההפרדה.
2. **ניגודיות** — `contrast.ts` בודק יחס ניגודיות WCAG בין הקוד לרקע (סורק ממיר
   את הפריים לבהירות, ולכן שני צבעים "שונים" יכולים ליפול על אותה בהירות).
   מתחת ל‑4.5:1 מוצגת אזהרה, מתחת ל‑3:1 אזהרה חמורה.
3. **פענוח חוזר** — `verify.ts` מרנדר את הקוד ב‑480px (רזולוציה של פריים מצלמה)
   ומפענח אותו בחזרה, דרך `BarcodeDetector` המובנה או `jsQR` כגיבוי. התוצאה
   מוצגת למשתמש מתחת לתצוגה המקדימה.

### בדיקת רגרסיה

```bash
npm run dev                    # בטרמינל נפרד, פורט 5174
npm run test:scan              # מרנדר כל עיצוב × 2 וריאציות × 3 גדלים ומפענח בחזרה
npm run test:export            # מוודא שכל פורמט ייצוא מפיק קובץ תקין
```

`test:scan` מפענח פעמיים: ברזולוציה המקורית, ובגרסה מוקטנת ל‑480px שמדמה מצלמת
טלפון — הנתיב המחמיר יותר ולכן הקובע. כרגע: **90/90**.
